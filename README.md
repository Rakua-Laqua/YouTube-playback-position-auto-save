# YouTube 再生位置自動保存 v1.8.1

YouTube の動画再生位置をブラウザ内に自動保存し、同じ動画を開き直したときに前回の続きから再開する Chrome 拡張機能です。

YouTube の視聴履歴を残さない設定で使っている場合でも、再生位置だけをローカルに保存できます。保存データは `chrome.storage.local` にのみ記録され、外部サーバーへ送信されません。

## 主な機能

- YouTube 動画の再生位置を自動保存（保存間隔は 5 秒・10 秒・30 秒から選択可能、既定 5 秒）
- 同じ動画を再訪問したときに保存位置へ自動復元
- 復元時は一時停止してからシークし、設定に応じて `seeked` 後に再生を再開
- 復元完了時に「○秒から再開します」のトースト通知を表示（ON/OFF 設定可能）
- 復元後の自動再生を ON/OFF 設定可能（オフにすると保存位置で一時停止したまま）
- 動画を最後まで視聴した場合に保存データを自動削除（ON/OFF 設定可能。OFF の場合は末尾位置を新規保存せず、既存データを残します）
- YouTube のページ内遷移、戻る/進む、タブ非表示、ページ離脱時にも保存
- 配信中ライブは保存・復元対象外として扱い、アーカイブ動画は通常動画として扱う
- 短時間だけ視聴した動画を保存しない設定（10秒・30秒・1分から選択）
- 古い保存データを自動削除する設定（30日・90日・180日から選択）
- 保存データを JSON ファイルでエクスポート／インポート可能
- ポップアップで保存済み動画の確認、検索、個別削除、有効/無効切り替えが可能
- 設定画面から保存データの一括削除、エクスポート、インポートが可能
- ポップアップから動画を開くとき、同じ動画の既存タブがあればそのタブへ切り替え（新規タブ固定に変更可能）
- 日本語・英語の多言語表示に対応

## 動作の流れ

1. YouTube の動画ページを開くと、`content.js` が動画 ID と動画要素を検出します。
2. 保存済みの再生位置がある場合、動画時間の整合性を確認してから復元します。
3. 復元可能な場合は動画を一時停止し、保存位置へシークします。設定が ON の場合はその後に再生を再開します。
4. 再生中は定期保存とイベント保存により、最新の再生位置を保持します。
5. 動画終了時、または終了 3 秒以内まで進んだ場合は終了扱いにします。自動削除が ON の場合は、その動画の保存データを削除します。

## 保存されるタイミング

- 再生中の定期保存（既定 5 秒、設定で 10 秒・30 秒に変更可能）
- 一時停止時
- YouTube 内で別動画へ移動したとき
- ブラウザの戻る/進む操作時
- タブが非表示になったとき
- ページを閉じる、または離脱するとき

復元中や動画終了後は、誤って古い保存位置を上書きしないように保存処理を抑止します。

## 復元されないケース

以下の場合は誤復元を避けるため、保存または復元を行いません。

- YouTube の動画ページではない
- 拡張機能がポップアップ設定で無効になっている
- 動画時間が取得できない、または無効な値になっている
- 保存時と現在の動画時間の差が 5 秒を超えている
- 現在配信中のライブ動画である
- 保存データが壊れている、または復元に必要な値を持っていない

配信中ライブはプレイヤー上のライブバッジの表示状態で判定します。配信終了後のアーカイブはライブバッジが非表示になるため、通常の動画と同じように保存・復元されます。

## ポップアップでできること

ツールバーの拡張機能アイコンをクリックすると、保存済み動画の一覧を確認できます。

- 保存済み動画数と概算ストレージサイズの表示
- 保存日時が新しい順での一覧表示
- タイトルまたは動画 ID による検索
- 動画タイトルをクリックして YouTube で開く
- 同じ動画の YouTube タブが既にある場合は、そのタブへ切り替え
- 動画ごとの保存データ削除
- 拡張機能の有効/無効切り替え
- 設定画面で各種動作をカスタマイズ（下記「設定項目」参照）
- 設定画面で保存データの一括削除、エクスポート、インポート

## 設定項目

ポップアップ右上の歯車アイコンから設定画面を開けます。

**保存と復元**

| 設定 | 既定 | 説明 |
| --- | --- | --- |
| 復元時に通知を表示 | ON | 保存位置へ移動したときにトースト通知を出す |
| 復元後に自動再生 | ON | オフにすると保存位置で一時停止したままにする |
| 短時間だけ見た動画を保存しない | 制限なし | 指定秒数未満の再生位置は保存しない（10秒・30秒・1分） |
| 最後まで見た動画を自動削除 | ON | オフにすると視聴完了後も既存の保存データを残す |

**一覧とデータ**

| 設定 | 既定 | 説明 |
| --- | --- | --- |
| 保存間隔 | 5秒 | 再生位置を保存する間隔（10秒・30秒も選択可） |
| 古い保存データを自動削除 | しない | ポップアップ起動時に古いデータを整理（30日・90日・180日） |
| 動画を開く方法 | 既存タブ優先 | 一覧から開くときのタブ動作（常に新しいタブも選択可） |

**データ管理**

| 操作 | 説明 |
| --- | --- |
| エクスポート | 保存データと設定を JSON ファイルに書き出す |
| インポート | JSON ファイルから保存データと設定を読み込む |
| すべて削除 | 保存されている全動画データを削除する |

## インストール方法

1. このフォルダをダウンロードします。
2. Chrome で `chrome://extensions/` を開きます。
3. 右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
5. このフォルダを選択します。

## 保存されるデータ

保存には `chrome.storage.local` を使用します。保存キーは `yt_position_<動画ID>` 形式です。

- 動画 ID
- 再生位置
- 動画の長さ
- 保存時刻
- ページタイトル

設定は `yt_position_settings` に保存されます。

## 権限

`manifest.json` では、現在以下の権限を使用しています。

- `storage`: 再生位置と設定をブラウザ内に保存するため
- `tabs`: ポップアップから同じ動画の既存 YouTube タブを探して切り替えるため
- `scripting`: 拡張機能の更新・再読み込み後に、既存の YouTube タブへ `content.js` を再注入するため
- `https://www.youtube.com/*`: YouTube ページ上で `content.js` を動作させ、既存タブへの再注入を許可するため

通常のページ読み込みでは `manifest.json` の `content_scripts` による自動注入を使用します。既に開いている YouTube タブに対しては、`background.js` が拡張機能の更新・再読み込み・ブラウザ起動・タブのアクティブ化・タブの読み込み完了時に再注入を試みます。`content.js` 側では再注入時に古いイベントリスナーやタイマーを掃除し、二重起動を防ぎます。

## 仕様（主要な定数）

| 項目 | 値 | 説明 |
| --- | --- | --- |
| `SAVE_INTERVAL_MS` | 5000 ms | 定期保存のフォールバック間隔（通常は設定値を使用） |
| `VIDEO_CHECK_INTERVAL_MS` | 100 ms | `<video>` 要素の検出間隔 |
| `VIDEO_CHECK_TIMEOUT_MS` | 5000 ms | `<video>` 要素検出のタイムアウト |
| `END_THRESHOLD_SEC` | 3 秒 | 動画末尾とみなして保存データを削除する閾値 |
| `DURATION_DIFF_THRESHOLD` | 5 秒 | 動画長の差がこれを超える場合は復元をスキップ |
| `SEEKED_TIMEOUT_MS` | 3000 ms | `seeked` イベントを待つ最大時間 |
| `NOTIFICATION_DURATION_MS` | 3000 ms | トースト通知の表示時間 |
| `NOTIFICATION_FADE_MS` | 500 ms | トースト通知のフェードアウト時間 |
| `POPSTATE_INIT_DELAY_MS` | 300 ms | `popstate` 後に初期化を遅延させる時間 |

## 注意事項

- YouTube の動画ページ（`https://www.youtube.com/watch?v=...`）でのみ動作します
- 配信中のライブ配信（DVR 含む）では、再生位置の保存・復元を行いません
- ブラウザの自動再生制限により、復元後の自動再生がブロックされることがあります（その場合は手動で再生してください）
- 動画の長さが大きく変わった場合（差が 5 秒以上）は、誤復元防止のため復元をスキップします
