# YouTube 再生位置自動保存

YouTubeの動画再生位置を自動的に保存し、再訪問時に復元する Chrome 拡張機能です。

> 📌 **履歴を保存しない人向け**  
> Youtubeの履歴を保存しない設定を使っている方でも、動画の再生位置を記録できます。
## 機能

- ✅ **自動保存** - 5秒ごとに再生位置を自動保存
- ✅ **再生位置復元** - 再訪問時に保存した位置から再開
- ✅ **スムーズな復元** - 最初の数秒が再生されることなく、保存位置から直接再生
- ✅ **通知表示** - 復元時に「〇〇秒から再開します」と表示
- ✅ **動画終了時削除** - 最後まで見た動画のデータは自動削除

## 保存タイミング

- 5秒ごとの定期保存
- 一時停止時
- 別の動画へ移動時
- 戻る/進むボタン押下時
- タブ切り替え時
- ページを閉じる時

## インストール方法

1. このフォルダをダウンロード
2. Chrome で `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. このフォルダを選択


## 注意事項

- YouTube の動画ページ（`https://www.youtube.com/watch?v=...`）でのみ動作します
- 広告再生中は保存されません（メインの動画のみ対象）
- 動画の長さが大きく変わった場合（5秒以上）、復元はスキップされます
